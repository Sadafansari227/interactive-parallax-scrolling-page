# ELSEWHERE — An Interactive Parallax Journey 🌍

**ELSEWHERE** is a cinematic, interactive parallax-scrolling website developed for the **Techfest, IIT Bombay – Interactive Parallax Scrolling Page Challenge**.

The website takes visitors through three immersive landscapes — Mountains, Ocean and Desert — using layered visuals, smooth scrolling, animations and creative UI/UX.

### 🌐 Live Prototype
https://sadafansari227.github.io/interactive-parallax-scrolling-page/

### ✨ Features
- Interactive multi-layer parallax scrolling.
- Three immersive landscape environments.
- Smooth animations and transitions.
- Cinematic visual design.
- Responsive layout.
- Interactive navigation and scroll progress indicator.

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
